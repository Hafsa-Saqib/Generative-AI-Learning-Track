# DHL Spain breakdown agreement

Carrier: DHL
Country: Spain
Commodity class: general

## 11.1 Mechanical breakdown

11.1.1 This clause applies only to general shipments to Spain carried by DHL.

11.1.2 A mechanical breakdown on a Spain lane has no weather-delay remedy and creates no breakdown refund.

11.1.3 The only weather clause on file is for a different carrier and does not apply to this breakdown.
