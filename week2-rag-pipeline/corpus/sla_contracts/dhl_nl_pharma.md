# DHL Netherlands pharma boundary

Carrier: DHL
Country: Netherlands
Commodity class: pharma

## 13.1 Certificate boundary

13.1.1 This clause applies only to pharma shipments to Netherlands carried by DHL.

13.1.2 DHL does not borrow the UPS one-business-day health-certificate notice.

13.1.3 A human has to check the DHL pharma file before any notice timeline is promised.
